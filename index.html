Install guide

Four steps

01

Install Fabric

Get the Fabric installer, choose Minecraft 1.21.11 and let it create a launcher profile.

02

Add Fabric API

Download Fabric API for 1.21.11. It goes in the same mods folder as everything else.

03

Adblocker on, then download

Switch your adblocker on, press Download on the mods you want, and ignore every other button on the page.

04

Drop the .jar files in

Put them in .minecraft/mods (Windows: press Win + R and enter %appdata%\.minecraft\mods), then launch the Fabric profile.

Questions

FAQ

Which Minecraft version and loader do I need?

Minecraft 1.21.11 on Fabric, plus Fabric API. Nothing here is built for other versions or for Forge.

Why is there an ad-filled page when I download?

The files are on a free host that shows ads. Use an adblocker and click only the real Download button. If something flashes, claims your file is ready, or asks you to install an extension or an .exe, close the tab. A mod is always a single .jar.

Is it safe to run these?

Any mod can run code on your computer, so only install ones you’re comfortable with. Mods marked Open source can be read by anyone. If you want a second opinion on a file, upload the .jar to VirusTotal before you use it.

Can I get banned for using them?

Possibly. Many servers don’t allow client mods, and rules differ from server to server. Read the rules of any server you join. You use these mods at your own risk — see the terms.

Glazed won’t load. What’s wrong?

Glazed needs Meteor Client and Fabric API in the same mods folder. Check all three are there and that they match 1.21.11.

A mod says “Updating — back soon”.

The download is switched off while a new version is being put up. Check the Discord for news, or come back in a bit.

Where do I get help or report a problem?

In the Discord. Changelogs, setup notes and support all live there.
