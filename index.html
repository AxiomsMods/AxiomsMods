Install in five steps

Takes about two minutes the first time. After that, updating is just swapping a file.

  1. 1
    Install Fabric Loader for 1.21.11

    Run the Fabric installer and pick Minecraft 1.21.11.

  2. 2
    Add Fabric API

    Download Fabric API for 1.21.11. Nearly every mod needs it.

  3. 3
    Download the mods you want

    Grab them from the list above. Adblocker on, real Download button only.

  4. 4
    Drop the .jar files into your mods folder

    Fabric API goes in there too. Don't unzip anything.

  5. 5
    Launch with the Fabric profile

    Pick "fabric-loader-1.21.11" in the Minecraft launcher and press Play.

Where's my mods folder?
Windows
%appdata%\.minecraft\mods — paste it into the File Explorer address bar.
macOS
~/Library/Application Support/minecraft/mods
Linux
~/.minecraft/mods
