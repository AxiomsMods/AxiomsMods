Branch (usually main)

Need a token? It takes a minute:
  1. Open GitHub → New fine-grained token.
  2. Name it Axiom admin and pick an expiry.
  3. Repository access: Only select repositories → choose your site's repo.
  4. Permissions → Repository → Contents: Read and write.
  5. Press Generate token, copy it, and paste it above.

The token stays in this browser only. Never share it — anyone with it can edit your site.
